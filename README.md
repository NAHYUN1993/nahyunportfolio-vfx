# LEE NAHYUN Portfolio — VFX Edition

The visual-effects edition of Lee Nahyun's portfolio. It keeps the original
portfolio content and adds a lightweight, dependency-free WebGL chlorophyll
field behind the work sections.

- The original portfolio remains at `nahyunportfolio`.
- Essential content and controls remain in the DOM.
- WebGL is limited to one canvas with a capped pixel ratio.
- Reduced-motion and no-WebGL environments receive a static visual fallback.
